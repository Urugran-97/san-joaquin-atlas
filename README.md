# San Joaquin County Atlas

A single-page, no-backend data site for San Joaquin County, California: crop history, population, a 3D terrain map and a scenario lab.
**Under development. Data may be incomplete, outdated, or contain errors. Scenarios are illustrative, not predictions.
Not for legal, financial, agricultural, medical, engineering, or land-use decisions; verify with official sources.**

- Code: MIT (`LICENSE`). Compiled data: CC BY 4.0, draft (`DATA-LICENSE.md`). Source terms still apply.
- Everything runs in the browser. No cookies, analytics or accounts.
- Report an error or a source that should not be shown: open a GitHub issue on this repository.

## Publish on GitHub Pages
1. Create a public repository and upload every file in this folder (all files sit at the top level; no folders; keep `.nojekyll`).
2. Settings > Pages > Deploy from a branch > `main` / root. The site appears at `https://<you>.github.io/<repo>/`.
3. Before sharing the link: search `index.html` for `[[` and replace every placeholder (the footer, the Terms and About pages).
